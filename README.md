# base-package-splectral

The Splectral platform: the server, its shell, the contract and model, transports, and the extensions for p2p swarms (watchers, actions, observer), scenarios, the timeline and replay; the map view (splectral/base-view-map), shared by the demos.

## The package

- holds: `pear-full-square/splectral-contract`, `pear-full-square/splectral-model`, `pear-full-square/splectral-transport`, `pear-full-square/splectral-server`, `pear-full-square/splectral-shell`, `pear-full-square/splectral-p2p-observer`, `pear-full-square/splectral-p2p-watchers`, `pear-full-square/splectral-p2p-actions`, `pear-full-square/splectral-scenario`, `pear-full-square/splectral-timeline`, `pear-full-square/splectral-replay`, `splectral/base-view-map`
- requires: [haiccing/base-package-p2p](https://github.com/haiccing/base-package-p2p)
- hash: `a43e93018c67806efc97305f0494bf855a60d09e7202faf31e189f834fbe7da6`

In a work folder (see [haiccing/base-package-haicc](https://github.com/haiccing/base-package-haicc)), installed by HAICC as a project needs it, or by `./haicc install splectral`, into `.haicc/packages` with what it requires; tested there, within the package: `./haicc test splectral`.
