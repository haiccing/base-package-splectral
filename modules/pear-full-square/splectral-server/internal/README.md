# internal/

The methods the actions and the server's program use, never requested.

| | |
|---|---|
| [serve/](serve/) | the server, in this process |
| [records/](records/) | a completed record summed up in a line, a folder of them followed |
| [structure/](structure/) | the install's structure folded from its completed records |
| [page/](page/) | the page the server serves |
| [process/](process/) | the server as its own process: the program, started, its state read, ended |

`config.js` is the protocol's config.
