# test/

The tests of splectral-server, a section per file, each test by its name.

## `server.test.js`

- a completed record summed up in a line
- a folder of records followed: what is there, the oldest first; then each that arrives, once
- the install folded from its completed records: its mrepos a tree, each with its state; a swarm node one node, its container part of it
- the site: its tabs, Splectral's own first; a section's page embedded in its content area, its links at the top; the rest in a drop-down; static
- the server: the site, its own page, the lines, one record whole, each new line streamed; closed
- the program as its own process: started, its state, answering; ended; ended by itself with its runtime, and with its folder
- the actions: start, status, stop; what start refuses
- a component: a page asked through its Splectral inbox, its data request run through the root mrepo's inbox, the page served; one not answering; one not running
